03 · From my notebook

How my research models are set up

A simplified sketch of the transfer-learning approach behind my insect species recognition research: a pre-trained backbone, frozen, with a new classification head trained on insect images.

insect_classifier.ipynb 
import tensorflow as tf
from tensorflow.keras.applications import EfficientNetB0

# Pre-trained ImageNet backbone, frozen for transfer learning
base = EfficientNetB0(include_top=False, weights="imagenet",
                      input_shape=(224, 224, 3))
base.trainable = False

model = tf.keras.Sequential([
    base,
    tf.keras.layers.GlobalAveragePooling2D(),
    tf.keras.layers.Dropout(0.3),
    tf.keras.layers.Dense(num_species, activation="softmax"),
])
model.compile(optimizer="adam",
              loss="categorical_crossentropy", metrics=["accuracy"])
